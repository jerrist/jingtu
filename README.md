# 经途 · 中级经济师人力方向刷题

手机优先的静态 PWA，覆盖经济基础知识与人力资源管理示例题库。

## 本地预览

在 `dist` 目录启动任意静态 HTTP 服务器即可。学习记录保存在浏览器 `localStorage` 中。

## 第一版功能

- 每日刷题计划与学习连续天数
- 双科章节练习
- 答题解析与错误原因记录
- 错题本和到期复习
- 15 分钟小模考
- 章节正确率与学习数据导出
- 独立 JSON 题库、结构版本和内容版本
- 单选、多选、案例单选及案例多选数据模型
- 题库自动校验脚本

> 当前内置题目为产品演示用示例题库，正式备考应替换或扩充为经授权、按最新考试大纲校验的题库。

题库结构说明见 `QUESTION_SCHEMA.md`。运行 `node scripts/validate-question-bank.cjs` 可检查题库完整性。
