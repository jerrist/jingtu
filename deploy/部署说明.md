# 经途刷题工具部署说明

推荐域名：`exam.jerrists.cloud`

部署采用不可覆盖的版本目录：

```text
/var/www/jingtu/
├── releases/
│   ├── v0.2.0/
│   └── v0.3.0/
└── current -> /var/www/jingtu/releases/v0.3.0
```

发布新版本只新增目录并切换 `current` 软链接，不删除历史版本，也不会接触浏览器里的做题记录。

## 首次部署

1. 在 DNS 中新增 A 记录：`exam` 指向 `120.79.17.230`。
2. 上传本目录中的发布包、Nginx 配置和脚本到服务器 `/tmp`。
3. 在服务器执行：

```bash
sudo mkdir -p /var/www/jingtu/releases
sudo cp /tmp/exam.jerrists.cloud.conf /etc/nginx/sites-available/exam.jerrists.cloud
sudo ln -s /etc/nginx/sites-available/exam.jerrists.cloud /etc/nginx/sites-enabled/exam.jerrists.cloud
sudo nginx -t
sudo systemctl reload nginx
sudo bash /tmp/deploy-release.sh /tmp/jingtu-hr-v0.2.0.tar.gz v0.2.0
sudo certbot --nginx -d exam.jerrists.cloud
```

## 后续更新

上传新版本发布包和脚本，然后执行：

```bash
sudo bash /tmp/deploy-release.sh /tmp/jingtu-hr-v0.3.0.tar.gz v0.3.0
```

始终使用同一个域名，且不要在程序升级时清理浏览器站点数据。`localStorage` 中的做题记录会保留。

## 回滚

```bash
sudo bash /tmp/rollback-release.sh v0.2.0
```

回滚只切换程序版本，不更改做题数据。
